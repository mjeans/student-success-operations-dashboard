# Reproducible dashboard graphics

## What these graphics are

The three README previews are static, data-driven SVG reports generated by
`scripts/render_previews.py`. They are not AI-generated charts, interactive
applications, or screenshots of a tested Power BI Desktop report. All source
records and school names are synthetic.

The design uses the existing `powerbi/theme.json` palette, a consistent
1600-by-1120 canvas, aligned cards, restrained gridlines, readable labels, and
explicit interpretation notes. There are no nonfunctional filter controls.

## Pages and source mapping

| Page | Content | Saved query sources |
|---|---|---|
| Executive overview | KPI units, participation, district support response, five leading schools and concentration | 02, 03, 04 and 06 |
| Implementation monitor | Counts at the correct row-level unit, eight leading schools, scored flags and the first school's action detail | 06 and 08 |
| Outcomes and participation | Paired changes by grade, participation, cohort sizes and follow-up completeness | 02, 03 and 05 |

Numbers refer to the filenames in `outputs/`. Full tables remain available there;
the school tables in the graphics are selected previews, not all schools.
The title and description inside each SVG identify its content and limitations.

## Visual and analytical safeguards

- Rates are plotted on a 0-100% axis. The score-change chart starts at zero.
- Percentage labels use one decimal place and explicit decimal half-up rounding.
  Formatting does not change source data or scoring decisions.
- Highlighted risk cells use the exported SQL flags, not comparisons against
  rounded display values. An exclamation mark supplements color.
- Trend lines differ in dash pattern and point shape as well as color. Direct
  endpoint labels and source-data links help readers inspect the series.
- Refresh age is shown in days, fidelity as a score, and rates as percentages.
- The action count is not a count of students or unique schools. The renderer
  reconciles per-school action counts, score flags and the executive risk count.
- Cohort sizes are not labeled as paired-score sample sizes. Locale and
  implementation-tier segments overlap. Separate baseline/follow-up means are
  not substituted for the within-student change measure.
- Suggested owners are proposals; the risk score is not a validated prediction.

These are practical accessibility features, not a claim of comprehensive
accessibility certification. Font fallback and rasterization can vary by viewer;
the SVG source and its text remain inspectable. Open the SVG at full size for
small labels, or use the CSV sources instead of reading a reduced thumbnail.

## Reproduce and verify

From the repository root, after regenerating the SQL outputs:

```bash
python scripts/render_previews.py
python scripts/render_previews.py --check
python -m unittest discover -s tests -v
```

The generator requires only Python's standard library. `--check` writes nothing
and fails when a committed SVG is missing or no longer matches the current
source outputs and theme. GitHub Actions runs this verification after rebuilding
the data and SQL outputs. `make all` includes SVG generation in its ordered stages.

The preview tests cover deterministic output, source-driven values, valid SVG
metadata, XML escaping, malformed rates, unknown schools, duplicate actions,
score reconciliation, empty action queues, rounding and stale-image detection.

## Scope and maintenance

The original `.png` files and Excel workbook are retained unchanged for existing
links and historical reference. The README now uses the `.svg` files. This does
not update the workbook or create a native Power BI report. The Power BI build
guide describes the separate interactive implementation still to be built.

The layout is designed for this case study, not arbitrary-size dashboards. A
future negative grade-level change currently raises an explicit error rather
than being clipped; add a signed-axis layout and tests before accepting such a
change. Review layout when labels, cohort structure, or the number of categories
change. Never edit CSV estimates to fit the graphic or regenerate a frozen
analytic baseline to conceal a failing test.
